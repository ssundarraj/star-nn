KNN and friends implemented for learning and fun.

## Layout

- `py/`: Python reference implementations, tests, demos, and visualizations.
- `cpp/`: C++ learning scaffold with headers, stub implementations, tests, examples, and a Makefile.
- `data/`: shared datasets used by the reference code and future C++ examples.

## C++

```sh
cd cpp
make build
make test
```

`make test` is expected to fail until the C++ algorithm stubs are implemented.
